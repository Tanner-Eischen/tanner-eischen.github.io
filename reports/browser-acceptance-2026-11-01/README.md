# Portfolio browser acceptance — November 1, 2026

Actual Chromium testing covered four home viewport widths (320, 390, 800 and 1440), six case studies, keyboard navigation, mobile menu/Escape/focus restoration, no-JavaScript reading, reduced motion, 24 byte-checked downloads, full-size figures and contained table scrolling. All 16 recorded check groups passed; seven pages had zero violations in the selected automated axe WCAG tags. Screenshots were inspected separately. This is not a claim of full accessibility conformance.
